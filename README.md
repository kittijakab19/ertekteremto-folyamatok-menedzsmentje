# Értékteremtő folyamatok menedzsmentje – 1. ZH tanulóoldal

Statikus tanulóoldal (BGE, Kalló Noémi előadásai alapján):

- **Jegyzet** – érték, porteri értéklánc, értékhálózat és ellátásilánc-menedzsment, számítások; teljes jegyzet és összefoglaló
- **Előadás** – a két diasor diánként, jegyzettel
- **Számolás** – beszállítóértékelés (súlyozott pontrendszer) és gravitációs központ, véletlen adatokkal, levezetéssel
- **Gyakorlás** – 243 kérdés, próba-ZH (16 kérdés, 40 pont) és gyakorló mód

Megnyitás: `index.html` böngészőben, vagy GitHub Pages-en. Build lépés nincs.
